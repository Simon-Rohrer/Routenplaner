# Routenplaner

Statischer Logistikplaner mit Leaflet-Karte und Routenberechnung.

## Lokal starten

### In VS Code

1. Projektordner in VS Code öffnen.
2. Im Bereich "Run and Debug" die Konfiguration "Logistikplaner lokal starten" auswählen.
3. Starten. VS Code öffnet `http://localhost:5500/index.html`.

### Im Terminal

```bash
python3 -m http.server 5500 --bind 127.0.0.1
```

Danach im Browser öffnen:

```text
http://localhost:5500/index.html
```
